# Wallakindle
Pocket has closed, which I used to use along with satellite services to send things I'm interested in to my kindle.

This is a personal setup I use to replace it.
It uses:

- wallabag
- an at-home script to send articles via mutt
- traefik to expose wallabar

Everything is deployed on a tini tiny server. It perfectly fits home server solutions if you fancy.
I've left SQLLite as my db. No need for extra complicated things since I'm a single user.

I you need something similar, it's a good starting point. Enjoy 😉
